# Bibliothèques externes (lib)

| Dossier | Contenu | Licence |
|---|---|---|
| `bootstrap/` | Bootstrap 5.3.2 (version Bootswatch, recolorée par `css/main.css`) | MIT |
| `fontawesome-free/` | Font Awesome Free 6.5.1 (icônes) | Icônes CC BY 4.0, polices SIL OFL 1.1, code MIT |
| `bootstrap-icons/` | petit fichier qui affiche les classes `bi bi-...` avec Font Awesome | MIT (projet Sanad) |

Le site fonctionne avec ces fichiers. Pour retrouver exactement le template **Medilab** (BootstrapMade) :
1. Téléchargez-le sur https://bootstrapmade.com/medilab-free-medical-bootstrap-theme/
2. Copiez le contenu de son dossier `assets/vendor/` ici (les fichiers existants seront remplacés), puis
   `assets/css/main.css` dans `Views/assets/css/` et `assets/js/main.js` dans `Views/assets/js/`.
3. Gardez `css/sanad.css`, `js/validation.js` et `img/sanad-icon.svg`.
