# Fichiers du template Medilab à ajouter ici

Les pages du Front Office utilisent les fichiers du template **Medilab** (BootstrapMade), qui ne sont pas encore dans le dépôt.

1. Téléchargez Medilab sur https://bootstrapmade.com/medilab-free-medical-bootstrap-theme/
2. Dans le zip, copiez le contenu du dossier `assets/` (`css/`, `img/`, `js/`, `vendor/`) dans ce dossier `frontoffice/assets/`.
3. Gardez les fichiers `css/sanad.css` et `img/sanad-icon.svg` déjà présents : ils appliquent la charte Sanad.
